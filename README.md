# Anu Fashion – UI/UX Design

A fashion shopping UI/UX project designed using Figma.

## About the Project

Anu Fashion is a user-friendly fashion shopping app/website designed to provide a simple and attractive online shopping experience.

## Tools Used

- Figma

## Main Screens

- Splash Screen
- Login / Sign Up
- Home Screen
- Category Screen
- Product Details
- Cart
- Checkout
- Payment
- Order Tracking

## My Role

UI/UX Designer

The complete UI design and prototype were created in Figma.
